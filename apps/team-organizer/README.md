# 체육쌤 스마트 팀 편성기

구글 스프레드시트를 명단 DB로 쓰는 **Google Apps Script 웹앱**입니다.
학급을 고르면 명단이 바로 뜨고, 결석 체크 → 조건 설정 → 팀 편성까지 한 화면에서 끝납니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 명단 불러오기 | `명단` 시트의 학급 / 번호 / 이름 / 성별 / 실력 |
| 학급 선택 즉시 로딩 | 학급을 고르는 순간 명단·이력을 함께 내려받음 |
| 결석 즉시 제외 / 복귀 | 이름을 누를 때마다 결석 ↔ 출석 전환 (전체 출석·결석 반전 포함) |
| 팀 수 2~20 | 스테퍼 + 빠른 선택 버튼, 팀당 예상 인원 표시 |
| 성별 균형 | 팀마다 남녀 비율을 전체 성비에 맞춤 |
| 실력 균형 | 상·중·하 분포와 팀 평균 실력을 함께 맞춤 |
| 같은 팀 조건 | 지정한 학생들을 항상 한 팀으로 |
| 다른 팀 조건 | 지정한 학생들을 서로 다른 팀으로 |
| 반복 조합 감소 | 최근 30회 이력에서 같은 팀이었던 짝을 피함 (최근일수록 강하게) |
| 완전 랜덤 우선 | 인원만 맞추고 나머지 균형은 모두 끄는 모드 |
| 활동/종목명 기록 | 이전에 쓴 활동명이 자동완성으로 뜸 |
| 팀별 통계 | 인원 / 성비 / 상·중·하 분포 / 평균 실력 |
| 다시 편성 · 복사 · 크게 보기 · 인쇄 | 크게 보기는 프로젝터용 전체화면 (Esc로 닫기) |
| 이력 저장 | `팀편성이력` 시트에 학생 1명당 1행으로 누적 |

편성 조건과 결석 체크는 학급별로 브라우저에 저장되어, 다음에 열어도 그대로 남아 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | 시트 읽기/쓰기, 이력 집계, 웹앱 진입점 |
| `Index.html` | 화면 구조 |
| `Styles.html` | 스타일 (팡팡 테마 · 인쇄 스타일 포함) |
| `Algorithm.html` | 팀 편성 알고리즘 (브라우저에서 실행) |
| `Script.html` | 화면 동작 (상태 관리, 렌더링, 서버 호출) |
| `appsscript.json` | 매니페스트 (시간대, 웹앱 설정) |

## 설치 (5분)

### 1. 스프레드시트 준비

새 구글 스프레드시트를 만들고 이름을 정합니다 (예: `체육 명단`).

### 2. Apps Script 프로젝트 만들기

스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
왼쪽 파일 목록에서 **＋** 버튼으로 아래 파일을 만들고 내용을 그대로 붙여넣습니다.
**파일 이름이 정확해야 합니다.**

- `Code.gs` (기본 생성된 `코드.gs` 이름을 `Code`로 변경)
- `Index` · `Styles` · `Algorithm` · `Script` → 모두 **HTML** 파일로 추가

`appsscript.json`을 편집하려면 **프로젝트 설정 → "appsscript.json" 매니페스트 파일을 편집기에 표시** 를 켜세요.

> `clasp`를 쓴다면 이 폴더에서 `clasp create --type sheets` 후 `clasp push` 한 번이면 됩니다.

### 3. 시트 초기 설정

스프레드시트를 새로고침하면 상단에 **팀 편성기** 메뉴가 생깁니다.
**팀 편성기 → 시트 초기 설정**을 누르면 `명단`, `팀편성이력` 시트가 만들어집니다. (권한 승인 1회 필요)

`명단` 시트 형식:

| 학급 | 번호 | 이름 | 성별 | 실력 |
| --- | --- | --- | --- | --- |
| 1학년 1반 | 1 | 김체육 | 남 | 상 |
| 1학년 1반 | 2 | 이운동 | 여 | 중 |

- **머리글 이름은 첫 줄에** 있어야 합니다. `학급`·`이름`은 필수, 나머지는 없어도 동작합니다.
- 대체 표기도 인식합니다 — 학급(`반`), 번호(`출석번호`, `학번`), 이름(`성명`), 실력(`수준`, `등급`, `레벨`).
- 성별은 `남`/`여`(`M`/`F`도 가능), 실력은 `상`/`중`/`하`(`A`/`B`/`C`, `3`/`2`/`1`도 가능). 비어 있으면 실력은 `중`으로 봅니다.

### 4. 웹앱으로 배포

Apps Script 편집기에서 **배포 → 새 배포 → 유형: 웹 앱**

- **실행 사용자**: 나
- **액세스 권한**: 나만 (교사 혼자 쓰는 경우) 또는 링크가 있는 모든 사용자

`appsscript.json`의 기본값은 `"access": "MYSELF"`입니다. 학생에게도 링크를 열어 주려면
`"access": "ANYONE_ANONYMOUS"`로 바꾼 뒤 다시 배포하세요. **명단이 그대로 노출되니 주의하세요.**

발급된 URL을 휴대폰 홈 화면에 추가해 두면 체육관에서 바로 쓸 수 있습니다.

### 독립형(standalone) 스크립트로 쓰는 경우

스프레드시트에 붙이지 않고 별도 프로젝트로 만들었다면, 편집기에서 한 번만 실행하세요.

```js
setSpreadsheetId('스프레드시트_ID');   // URL의 /d/ 와 /edit 사이 문자열
```

## 사용법

1. **학급 선택** → 명단이 바로 뜹니다.
2. **결석 체크** — 결석한 학생 이름을 누릅니다. 다시 누르면 복귀합니다.
3. **활동명·팀 수 입력** — 활동명은 이력에 함께 저장됩니다.
4. **편성 방식 선택** — 성별/실력/반복 조합. 그냥 뽑기만 할 땐 *완전 랜덤 우선*.
5. **조건 추가** — `＋ 같은 팀으로 묶기` / `＋ 서로 다른 팀으로`에서 학생 2명 이상 선택.
6. **팀 편성하기** → 마음에 안 들면 **다시 편성**을 계속 눌러도 됩니다.
7. **복사 / 크게 보기 / 인쇄**로 학생들에게 공유하고, **이력 저장**으로 시트에 기록합니다.

이력을 저장해 두어야 다음 시간에 *반복 조합 줄이기*가 작동합니다.

## 편성 알고리즘

1. `같은 팀` 조건으로 묶인 학생들을 하나의 덩어리로 만듭니다.
2. 무작위 그리디로 초기 배치를 만들고, 이동·교환 지역 탐색으로 비용을 낮춥니다.
3. 이를 14회 반복(멀티 스타트)해 가장 좋은 결과를 고릅니다. 그래서 **다시 편성**을 누를 때마다 결과가 달라집니다.

비용 = 인원 편차 + 성별 편차 + 실력 편차(평균·분포) + 과거 반복 조합 + 조건 위반

가중치는 `Algorithm.html` 상단에서 조정할 수 있습니다.

```js
var W_SIZE = 1000;      // 팀 인원 균등 (항상 적용)
var W_GENDER = 45;      // 성비 균형
var W_LEVEL_SUM = 30;   // 팀 평균 실력
var W_LEVEL_DIST = 12;  // 상/중/하 분포
var W_HISTORY = 9;      // 과거 같은 팀 반복
var W_VIOLATION = 1e7;  // 다른 팀 조건 위반
```

이력 반영 범위는 `Code.gs`의 `HISTORY_SESSION_LIMIT`(기본 30회)과 `HISTORY_DECAY`(기본 0.85, 회차가 오래될수록 가중치 감소)로 바꿉니다.

조건이 서로 충돌하거나(같은 팀 + 다른 팀), 팀 수보다 많은 학생을 서로 떼어 놓으라고 하면
편성은 그대로 진행하되 결과 위에 경고를 띄웁니다.

## `팀편성이력` 시트

학생 1명당 1행으로 쌓입니다.

| 저장시각 | 날짜 | 학급 | 활동 | 팀수 | 팀 | 번호 | 이름 | 성별 | 실력 | 세션ID |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

- 같은 `세션ID`가 한 번의 편성입니다.
- 이 시트를 지우면 반복 조합 이력도 초기화됩니다. 특정 회차만 지우려면 해당 `세션ID` 행을 지우세요.
- 피벗 테이블로 학생별 팀 배정 횟수를 바로 뽑아 볼 수 있습니다.

## 팡팡 홈페이지에 연결하기

루트 `index.html`의 `모둠편성` 카드는 `modoom.html`을 가리킵니다.
배포한 웹앱 URL로 바꾸면 홈페이지에서 바로 연결됩니다.

```js
'모둠편성': {
  href: 'https://script.google.com/macros/s/…/exec',
  …
}
```

## 문제 해결

| 증상 | 확인할 점 |
| --- | --- |
| `명단 시트를 찾을 수 없습니다` | 메뉴 **팀 편성기 → 시트 초기 설정** 실행, 시트 이름이 정확히 `명단`인지 확인 |
| 학급 목록이 비어 있음 | `명단` 시트 첫 줄에 `학급`, `이름` 머리글이 있는지 확인 |
| 명단을 고쳤는데 반영이 안 됨 | 우측 상단 **새로고침** 버튼 |
| 반복 조합이 안 줄어듦 | 지난 편성을 **이력 저장** 했는지, 학급명·번호·이름이 이력과 같은지 확인 |
| 복사 버튼이 안 먹음 | 브라우저 정책 문제입니다. **크게 보기**나 **인쇄**를 쓰세요 |
| 인쇄가 어긋남 | 결과 화면에서 인쇄하면 설정 패널은 자동으로 빠집니다. 가로 방향 권장 |
